# ИЦП: аудит датасета Titanic

Это учебная работа по анализу данных о пассажирах «Титаника».

В файле `Titanic_Data_Audit.ipynb` я проверил датасет: его размер, пропуски, дубликаты, значения в столбцах и соотношение выживших и погибших пассажиров.

Датасет находится в `data/titanic_train.csv`. В нём 891 строка и 12 столбцов. Главный столбец — `Survived`: `1` означает, что пассажир выжил, `0` — не выжил.

В ходе проверки выявлены пропуски в возрасте, каюте и месте посадки. В ноутбуке указано, как можно подготовить эти данные для следующего этапа — построения модели.

Источник датасета: [Kaggle Titanic](https://www.kaggle.com/competitions/titanic/data).

## Как запустить

- На компьютере: откройте `Titanic_Data_Audit.ipynb` в Jupyter Notebook и запустите ячейки по порядку.
- В Google Colab: откройте ноутбук, нажмите «Выполнить всё». Если Colab попросит файл, выберите `data/titanic_train.csv` со своего компьютера.
